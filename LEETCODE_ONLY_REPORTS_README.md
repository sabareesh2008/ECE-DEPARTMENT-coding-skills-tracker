# LeetCode-only reports

Daily: exact previous-day 07:00 AM to current-day 07:00 AM IST. The report is named by the starting date.

Weekly: exact previous 7 days, 07:00 AM to 07:00 AM IST.

Included: LeetCode metrics, exact report-window accepted problems, 7/14/30-day solved, 7-day submissions, Total Submissions, total solved, E/M/H, daily inactive students, top/bottom and section summaries.

Removed: Daily Challenge and Coding Test sections/data.

Inactive students are only students with 0 accepted problems AND FULL window coverage. PARTIAL/ERROR zero profiles are kept as unverified, not falsely called inactive.
