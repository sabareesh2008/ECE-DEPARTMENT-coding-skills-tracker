C O D E M E T R I X 01
THE CHALLENGE

Problem Statement

Students practice coding on platforms like LeetCode and GitHub, but faculty often lack a centralized system to track and evaluate that progress effectively.

📋

Manual Tracking

Manual tracking of students' coding progress across hundreds of individual profiles.

👥

Hard to Monitor at Scale

Difficult to monitor hundreds of students and keep records continually up to date.

👤✕

Inactive Students Missed

Faculty cannot easily identify inactive students early for academic counseling.

🔀

Scattered Data & Copy-Paste

Coding submissions are scattered across platforms without any code integrity verification.

📊

No Easy Comparison

Difficult to compare section-wise performance, daily streaks, and authentic logic building.

🗂️

Database Storage Exhaustion

Saving raw code files rapidly consumes free cloud quotas without an automated 50-limit purge.

C O D E M E T R I X 04
HOW IT WORKS

System Architecture

LeetCode • Problems solved (E / M / H)  • Daily activity & submissions
GitHub • Repositories & commits  • Contribution heatmap activity
Python — Processing Engine • Fetch data  • Process & clean  • Validate deduplication  • Enforce 50-limit window
GitHub Actions • Scheduled execution  • Runs trackers automatically
Supabase (PostgreSQL) • Central data store  • Auto-prune triggers  • Powers all dashboards
Student Dashboard • Solved breakdown  • 1-Click ZIP archive
Faculty Analytics • Section comparison  • In-modal code viewer
Admin Dashboard • Anti-paste forensics  • Excel reports
C O D E M E T R I X 05
WHAT IT DELIVERS

Key Features

⚡

Automated LeetCode & GitHub Tracking

Daily background scraping captures solved counts, streaks, and difficulty breakdowns automatically.

📊

Section-wise Analysis

Instant filtering across sections with ranked leaderboards and detailed student modals.

👤✕

Inactive Students Detection

Early identification of students with broken practice streaks for prompt academic mentoring.

⚠️

Suspicious Solving & Anti-Paste

Extension tracks typing vs paste deltas to flag AI-pasted code while keeping short one-liners clean.

📦

50-Problem Download & Auto-Purge

1-click ZIP and Excel archive of solved files with automatic database reset to maintain free cloud limits.

🔄

Duplicate Prevention

Re-submitted problems automatically replace older records, guaranteeing zero duplicate entries.
